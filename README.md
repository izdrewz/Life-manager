# Life Manager

A mobile-first, ADHD-friendly cleaning and room-care app.

## Current working features

- Main screen with one current task
- Recovery and maintenance states
- Minimum and Full task versions
- One-step-at-a-time active sessions
- Repeat-until-Yes dish transport loop
- Preservation pre-check for disruptive tasks
- Colour-coded task categories
- Searchable task library
- Add, edit and delete permanent or one-off tasks
- Permanent category management
- Advice library
- Exact history and resume records
- Gradual wardrobe logging
- Persistent Index / I’m lost directory
- Copyable ChatGPT support prompts
- Calm and decorated appearance modes
- Local JSON export and import
- Browser-local storage with no account or backend

## Files

- `index.html` — app shell
- `styles.css` — mobile-first visual system and category colours
- `app-part-1.js` to `app-part-8.js` — application bundle
- `app-loader.js` — starts the bundled application

## Data and privacy

The app currently stores data in the browser using `localStorage`. Export JSON backups before relying on one browser or device.
