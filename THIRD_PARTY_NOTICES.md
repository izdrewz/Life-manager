# Third-party notices

This branch is a separate React rebuild of Life Manager. The existing live site on `main` is not replaced by this branch.

## DailyWave

DailyWave by its contributors is licensed under the Apache License 2.0.

Life Manager uses DailyWave as an architectural reference for a React/Vite local-first application, including the ideas of a simple default view, one clear next step, sequential workflows, autosave, optional calendar integration and responsive presentation.

DailyWave name, logo and branding are not used by Life Manager.

Source: https://github.com/kks0488/dailywave
Licence: https://www.apache.org/licenses/LICENSE-2.0

## Ilseon

Ilseon by Claes Adamsson is licensed under the MIT License.

Life Manager adapts its focus-first interaction principles: one current priority, sequential subtasks, instant capture and low-friction context filtering. The Android Jetpack Compose source is not used as the web application runtime.

Source: https://github.com/cladam/ilseon

## TinyTask

TinyTask by Team Cyberpunk is licensed under the MIT License.

Its task/event separation and scheduling concepts are references for later Calendar integration. TinyTask branding and React Native interface assets are not included.

Source: https://github.com/SagarPateI/TinyTask
